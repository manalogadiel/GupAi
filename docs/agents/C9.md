# C9 — Offline Filipino voice

User authorized improving Tagalog speech across the running app. Replaced the default English browser fallback with local OmniVoice Filipino generation (male voice, 8 steps, fixed seed). Displayed/persisted replies remain unchanged. Speech-only normalization expands numbers and removes markup.

Files: backend/app/tts.py, backend/app/main.py, backend/app/jobs.py (startup warmup), backend/requirements-tts.txt, scripts/setup-tts.py, backend/tests/test_tts.py, frontend/src/speech.ts, frontend/src/components/Scenes.tsx, frontend/tests/speech.test.ts.

New additive endpoint: POST /api/consultations/{id}/speech with {turn_index: integer}. Requires existing consultation scope and matching Origin; reads only a persisted AI turn. Returns audio/wav with Cache-Control no-store. Invalid/non-AI turns: 422; missing scope: 404; missing local model: 503; busy model: 409. No arbitrary text synthesis endpoint. Concurrent requests reject rather than queue. Browser playback cancels pending requests and audio on mute, navigation, or superseding replies; falls back to on-device speech on failure. Browser timeout 30 seconds.

Dependencies: torch 2.8.0, torchaudio 2.8.0, transformers 5.19.0, omnivoice 0.2.1 and their pip-resolved transitive dependencies (including accelerate, soundfile, librosa and OmniVoice's gradio dependencies). pip check: no broken requirements. Install using .venv/bin/python -m pip install -r backend/requirements-tts.txt then .venv/bin/python scripts/setup-tts.py. Model weights in ignored data/models/omnivoice (~3.27 GB). Runtime loads local paths only, verifies required files first; server launched with HF_HUB_OFFLINE=1 and TRANSFORMERS_OFFLINE=1. No reference voice cloning used.
